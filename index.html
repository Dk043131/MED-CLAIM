    90-Second Demo Script

    Demo Run Order

    Follow this exact sequence during the judging panel. Rehearse at least twice with a stopwatch.

    1. ① Hook (15s): "A coding error on one line of a hospital bill can push a family into debt." Open MED-CLAIM dashboard.
    2. ② Clean bill (20s): Upload clean bill → watch all 5 stages turn green → Auto-Approved verdict.
    3. ③ Messy bill (20s): Upload handwritten bill → watch OCR struggle → Flagged verdict → switch to HITL queue.
    4. ④ HITL review (15s): Expand flagged claim, show image + extracted JSON side-by-side, click Approve.
    5. ⑤ Surge Mode (15s): Switch to dashboard → click SURGE MODE → watch charts climb live. Close on 90%+ auto-rate.
    Verification Checklist

    Q&A Prep

    Likely Judge Questions

    • 💬 Why only 3 screens? Scope discipline. Each screen maps to one real-world user (patient/submitter, caseworker, manager). More screens = more surface area to break in demo.
    • 💬 How does HITL help a caseworker? Original image + extracted JSON side-by-side eliminates paper-hunting. One-click approve with audit trail. Average review time <30 seconds.
    • 💬 How is auto-adjudication rate calculated? Approved claims ÷ total claims. Recomputed live on every state change. 90%+ means 9 in 10 claims need zero human time.
